# Product photos for the demo shop (made with the free Gemini website)

The 13 seeded products have no photos yet. These prompts are for https://gemini.google.com
(free with a Google account). They are demo images for the portfolio, not real products.

## How to do it

1. Open gemini.google.com and start a **new chat for each product** (an old chat can drift the style).
2. Copy one prompt below, paste it, send.
3. If the result is good, download it. If the label text is misspelled or the packaging is wrong,
   reply "Try again, same setup" or point out what to fix.
4. Save the file with the name shown above the prompt (for example `01.png`) into one folder:
   `public/uploads/products/demo/` in this project. Use .png or .jpg, whatever Gemini gives you
   (keep the number, the extension may differ).
5. When all 13 are in that folder, tell Claude: it will attach each file to the right product.
   (Or upload them one by one yourself in Dashboard > Products > Edit.)

Note: free Gemini images carry a small visible Gemini mark in a corner. The shop crops photos to
a 4:5 frame, so it may be partly cut off; that is fine for a demo.
